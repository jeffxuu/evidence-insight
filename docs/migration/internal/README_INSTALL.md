## Release purpose

V7.6.3 is an **Authorial Stance Patch** for Social output.

It fixes a specific remaining failure:
Social could be accurate and artifact-pure, yet still read like a neutral third-party research note.

## New Social model

Stance → Evidence Arc → Implication

This is a priority order, not a fixed template.

### Hook
The first 1–2 sentences should reveal the interpretive payoff quickly.

### Authorial Ownership
The caption must communicate one evidence-backed judgment the author is willing to publish under their own name.

First person is optional.

### Evidence Arc
Use only the minimum facts and mechanism required to support the stance.

### Implication
End by moving the interpretation forward when evidence supports it.
Do not merely summarize the opening.

## Not added
- no mandatory first person
- no mandatory metaphor
- no rigid three-paragraph structure
- no forced reversal
- no new score system

## Unchanged
- multi-source intake
- Research Engine
- Qualified Evidence Pool
- Analysis Renderer
- Artifact Boundary
- adaptive Social length
- Semantic Strength Lock
